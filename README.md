# Structural Signal Decomposition

A Scala framework for decomposing composite system signals into latent structural components and measuring persistence across observation windows.

## Overview

This repository explores a lightweight structural decomposition model using weighted observations, variance, volatility, persistence, and normalization.

## Core Components

- Weighted mean estimation
- Variance and volatility measurement
- Directional persistence scoring
- Observation normalization
- Structural component extraction
- Component ranking

## Language

Scala
